# PULSE — heartbeat sensor

A Call of Duty–style heartbeat sensor app for your phone.

**Live app:** https://andersondaniel48-dot.github.io/pulse/ (open in Chrome on Android)

- **SIM** — simulated contacts; tap the screen to drop/remove one.
- **SONAR** — the phone's speaker + mic as ultrasonic sonar (~2 m, line of sight). Allow the microphone when asked.
- **LINK** — connects over Bluetooth to a PULSE-PUCK (ESP32 + HLK-LD2450 radar). Firmware: `pulse_puck.ino`.
